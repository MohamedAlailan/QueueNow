# QueueNow Clinic

QueueNow Clinic is a web-based clinic management system designed to organize patient appointments, manage queues, and streamline the patient journey from check-in to medical consultation.

## Project Overview

The system aims to provide a simple and efficient platform for managing the basic operations of a medical clinic.

### Main Users

- Patient
- Doctor
- Receptionist
- Admin

### Main Features

- User authentication and role-based access
- Patient management
- Doctor management
- Appointment booking and management
- Queue management
- Medical visit records
- Prescription management
- Notifications
- Basic dashboard and reports
- AI-assisted features
